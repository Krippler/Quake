The mouse is captured either way, so it cannot slide out of the picture while you turn. Sound plays in this tab.

Esc releases the mouse and brings this screen back — which is why Game menu is here rather than on a key: the browser takes Esc while the mouse is captured, and Esc is what opens Quake's menu. The ` key opens the console. Keys, the mouse and the sound are all configured in the game's own Options.

Buttons

Each action presses a key, so it has to be the key your game listens for. Those are read from the game's own config and shown below — green came from there, pink was set here by hand, grey is the engine default. If one is wrong, press Key on its row and then the key you actually use.
